Connect your agents no agents yet

Add Prophecy to Cursor in one click, or paste the settings into Claude Code or any other MCP client. They talk to this Prophecy over HTTP, on this machine or another.

An agent writing code here does not have to read the tree to find its way in. It asks, over MCP, and gets the slice: the files this task is predicted to touch, the symbols in them and their line numbers, drawn from the dependency graph plus what is uncommitted, what changed recently, and what another session has already claimed. And it works both ways: when you send an agent the risk profile of what it is doing, that reading is waiting for it the next time it asks anything.

The agent asks
  • join_repo_session: the slice to start from, who else is here, and what they have already worked out
  • analyze_change: what this change would break, before committing it
  • check_overlap: whether these files are somebody else's files too
  • get_change_interactions: what this change looks like next to everything else in flight
  • get_dependency_context: one file's exports with line numbers, instead of reading the whole file
  • share_finding: hands something back for the next agent that goes there
Prophecy answers
  • the predicted slice: files, symbols, line numbers, so nothing has to be hunted for
  • a risk score with its range and confidence, not a verdict
  • the files and callers that would actually be hit
  • the other work it is about to collide with, by name
  • anything you sent from , delivered on the agent's next call
